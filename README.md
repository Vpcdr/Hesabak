## راه‌اندازی در GitHub Pages
1. یک مخزن (Repository) بسازید و همه فایل‌های این پوشه را در ریشه آپلود کنید.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. بعد از یکی دو دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.
4. روی گوشی: منوی مرورگر ← «افزودن به صفحه اصلی».
